📄 Web Practice Projects

This repository contains a collection of HTML practice files created for learning web development basics such as forms, input handling, and simple page layouts.
It’s intended for beginners who want hands-on experience building web pages.

📂 What’s Inside

The repository includes the following HTML files:

event.html – A file for learning HTML event attributes

form.html – A basic form example

inputs.html – Form input fields practice

practice.html – General HTML practice page

recipe.html – A simple structured recipe page

registration.html – A registration page example

These files help you practice and understand HTML structure, tags, forms, and page layout.

🚀 How to Use

Clone the repository:

git clone https://github.com/KillamsettiMonika/repo1.git


Open the folder in your code editor.

Open any .html file in a web browser to view and test your web pages.
